# Welcome Luggage & Repairing Center (MFA Agency)

<p>
  <strong>High-performance Next.js 15 Web Application</strong> for Gaya's premier luggage repair workshop. Built with a focus on Local SEO, performance, and modern UI/UX.
</p>

<hr />

## 🚀 Tech Stack
<ul>
  <li><strong>Framework:</strong> Next.js 15 (App Router)</li>
  <li><strong>Styling:</strong> Tailwind CSS</li>
  <li><strong>Animations:</strong> Framer Motion & CSS3</li>
  <li><strong>Icons:</strong> Lucide React</li>
  <li><strong>Personalization:</strong> Hybrid Server/Client Components</li>
</ul>

## 🛠 Features
<article>
  <ul>
    <li><strong>SEO Optimized:</strong> Semantic HTML5 tags and JSON-LD for Google ranking.</li>
    <li><strong>Zero-JS FAQ:</strong> Performance-first <code>&lt;details&gt;</code> elements for instant support.</li>
    <li><strong>Storytelling:</strong> Narrative layout detailing the shop legacy from Dehri-on-Sone to Gaya.</li>
    <li><strong>Responsive:</strong> Adaptive layouts for all screen sizes.</li>
  </ul>
